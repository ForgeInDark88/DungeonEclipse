# Звуки и музыка — что заменить своими файлами

Все звуки сейчас — синтезированные заглушки из `tools/gen_audio.py` (WAV, моно, 22 кГц).
Чтобы заменить звук, положите свой файл с **тем же именем** в ту же папку. Можно OGG/MP3 —
тогда поменяйте расширение в `scripts/core/asset_paths.gd` (словари `SFX` и `MUSIC`).
Если файла нет, звук просто не играет (игра не падает).

## Шины и громкость

`AudioManager` (autoload) создаёт шины **Music**, **SFX**, **UI** (все идут в Master).
Громкость каждой шины настраивается в главном меню и сохраняется в `user://settings.cfg`.
Звуки мира позиционные (AudioStreamPlayer2D, затухают с расстоянием), UI — нет.
У каждого воспроизведения слегка случайный питч, поэтому вариантов одного звука не нужно.

## Музыка — `assets/audio/music/`

Сейчас в папке лежат синтезированные заглушки (`tools/gen_audio.py`). Настоящие треки
кладите с тем же именем (`.wav` или `.ogg`; для `.ogg` поменяйте расширение в
`AssetPaths.MUSIC`). Если файла нет, игра работает без ошибок: для боссов сначала берётся
общий `boss` (`AssetPaths.MUSIC_FALLBACK`), иначе тишина. Петли зацикливает сам
`AudioManager`, флаг loop в импорте не нужен.

| id | Файл | Где звучит | Настроение | Длительность | Loop |
|---|---|---|---|---|---|
| `menu` | `music_menu.wav` | Главное меню, создание героя, Святилище, Летопись, ежедневный забег | Тихая тревожная баллада, «перед спуском» | 1–2 мин | да |
| `catacombs` | `music_catacombs.wav` | Биом «Катакомбы» (этажи 1–3, 13–15…) | Сырой камень, капель, низкие струнные | 2–3 мин | да |
| `fungal` | `music_fungal.wav` | «Грибные пещеры» (4–6…) | Таинственно, мерцающие колокольчики, мажор с примесью | 2–3 мин | да |
| `ruins` | `music_ruins.wav` | «Руины» (7–9…) | Торжественная печаль, древний храм, хор | 2–3 мин | да |
| `lava` | `music_lava.wav` | «Лавовые глубины» (10–12…) | Тяжёлый пульс, низкие барабаны, жар | 2–3 мин | да |
| `boss` | `music_boss.wav` | Общая тема арены (запасная для любого босса) | Напряжённо, быстрый ритм | 1.5–3 мин | да |
| `boss_bone_king` | `music_boss_bone_king.wav` | Арена Короля костей (этажи 5, 15…) | Мрачный марш, костяные перкуссии, орган | 1.5–3 мин | да |
| `boss_flame_witch` | `music_boss_flame_witch.wav` | Арена Владычицы пламени (этажи 10, 20…) | Яростно, быстрые струнные, огонь | 1.5–3 мин | да |
| `victory` | `music_victory.wav` | Сразу после победы над боссом, затем возврат к музыке биома | Триумф, восходящая фанфара | 3–6 с | нет |
| `death` | `music_death.wav` | Гибель героя (экран итогов) | Скорбный нисходящий мотив | 4–8 с | нет |

**Когда что играет.** Меню → `menu`. Этаж → `BiomeData.music`. Вход в арену босса →
`BossData.music`. Победа над боссом → `victory` один раз, затем снова музыка биома.
Гибель → `death` один раз, после него тишина до выхода в меню. Все смены — кросс-фейд
1.5 с (`AudioManager.MUSIC_FADE`).

**Новый трек.** Добавьте строку в `AssetPaths.MUSIC`. Если трек одноразовый, добавьте его id
в `AssetPaths.MUSIC_ONE_SHOT`; если нужен запасной, укажите его в `AssetPaths.MUSIC_FALLBACK`.
Затем задайте id в данных (`BiomeData.music`, `BossData.music`) или вызовите в коде
`AudioManager.play_music(id)` / `AudioManager.play_sting(id, затем_id)`.

## Как добавить новый звук

1. Положите файл в `assets/audio/sfx/`.
2. Добавьте строку в `AssetPaths.SFX`: `&"my_sound": SFX_DIR + "my_sound.ogg",`.
3. Используйте id в данных (`UsableItemData.use_sound`, `EnemyData.sound_hurt/sound_death/sound_attack`)
   или в коде: `AudioManager.play_sfx(&"my_sound", global_position)` / `AudioManager.play_ui(&"my_sound")`.
