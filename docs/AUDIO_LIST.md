# Звуки и музыка — что заменить своими файлами

Все звуки сейчас — синтезированные заглушки из `tools/gen_audio.py` (WAV, моно, 22 кГц).
Чтобы заменить звук, положите свой файл с **тем же именем** в ту же папку. Можно OGG/MP3 —
тогда поменяйте расширение в `scripts/core/asset_paths.gd` (словари `SFX` и `MUSIC`).
Если файла нет, звук просто не играет (игра не падает).

## Шины и громкость

`AudioManager` (autoload) создаёт шины **Music**, **SFX**, **UI** (все идут в Master).
Громкость каждой шины настраивается в главном меню и сохраняется в `user://settings.cfg`.
Звуки мира позиционные (AudioStreamPlayer2D, затухают с расстоянием), UI — нет.
У каждого воспроизведения слегка случайный питч, поэтому вариантов одного звука не нужно.

## Музыка — `assets/audio/music/music_<id>.wav` (зацикливается)

| id | Где | |
|---|---|---|
| `menu` | Главное меню и создание героя | 30 с – 3 мин, бесшовная петля |
| `catacombs` | Биом «Катакомбы» (этажи 1–3, 13–15…) | 30 с – 3 мин, бесшовная петля |
| `fungal` | «Грибные пещеры» (4–6…) | 30 с – 3 мин, бесшовная петля |
| `ruins` | «Руины» (7–9…) | 30 с – 3 мин, бесшовная петля |
| `lava` | «Лавовые глубины» (10–12…) | 30 с – 3 мин, бесшовная петля |
| `boss` | Арена босса (появится с боссами) | 30 с – 3 мин, бесшовная петля |

Переход между треками — плавный кросс-фейд 1.2 с. Трек биома задаётся `BiomeData.music`.

## Как добавить новый звук

1. Положите файл в `assets/audio/sfx/`.
2. Добавьте строку в `AssetPaths.SFX`: `&"my_sound": SFX_DIR + "my_sound.ogg",`.
3. Используйте id в данных (`UsableItemData.use_sound`, `EnemyData.sound_hurt/sound_death/sound_attack`)
   или в коде: `AudioManager.play_sfx(&"my_sound", global_position)` / `AudioManager.play_ui(&"my_sound")`.
