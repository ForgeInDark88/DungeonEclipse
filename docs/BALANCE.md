# Баланс лута и сложности

Отчёт создан `tests/loot_sim.tscn` (1000 открытий каждой таблицы на этаж, фиксированное зерно).
Таблицы настраиваются в `tools/gen_loot_tables.py`, после правки: `python3 tools/gen_loot_tables.py`
и `godot --headless --path . res://tests/loot_sim.tscn` (перезапишет этот файл).

Предел уровня предмета: `1 + 0.75 × этаж + бонус таблицы` (деревянный сундук +0, железный +1,
золотой +2, особые комнаты +2, босс +3). Редкости открываются с этажа `rarity_min_floor`.
Доли редкостей — по всем выпавшим предметам (кроме золота); уровень — только по снаряжению.

## Сила и число монстров

HP × (1 + 0.46 × (этаж − 1)), урон × (1 + 0.24 × (этаж − 1)); монстров на этаже: 3 + 2.4 × этаж + комнаты / 2;
элита: 6% на 1-м этаже, +2.5% за этаж, максимум 35%. Аффиксы элиты: быстрый, огненный, регенерирующий,
вампирский, бронированный, щитоносный (щит поглощает урон). Элита: ×2.5–3 опыта, ×3–3.5 золота,
осколок Затмения и гарантированный лут из `enemy_rare`.
