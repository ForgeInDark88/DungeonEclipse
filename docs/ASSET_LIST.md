# Список ассетов-заглушек локаций «поверхность + данж»

Здесь — то, что появилось начиная с этапа 14 (слои локации). Остальные
заглушки описаны в `docs/ASSETS_TODO.md`. Замените PNG файлом с тем же
именем и размером. Если новый спрайт крупнее, поправьте смещение в коде,
где он рисуется.

## Пути между слоями — `assets/sprites/portals/`
Генератор: `python3 tools/gen_location_art.py`.

| Файл | Размер | Что это | Где |
|---|---|---|---|
| `cave.png` | 44×36 | Главный вход в подземелье на поверхности (пещера в холме) | `LayerPortal`, kind `entrance` |
| `cave_mossy.png` | 44×36 | Боковой лаз вниз (заросший мхом вход) | kind `side` |
| `stairs_down.png` | 28×36 | Лестница на этаж ниже | kind `down` |
| `stairs_up.png` | 28×36 | Лестница наверх, со светом сверху | kind `up` |
| `map_exit.png` | 22×32 | Дорожный указатель «на карту похода» в начале поверхности | kind `map` |
| `arena_exit.png` | 32×36 | Рунный круг-подъёмник из логова стража (появляется после победы) | kind `arena_exit` |

Будет дополняться на этапах 15–19: тайлы и фоны поверхности по биомам,
мобы поверхности, ресурсы, входы разных видов, лагерь.

## Виды входов вниз с поверхности — `assets/sprites/portals/`
Генератор: `python3 tools/gen_location_art.py`. Вид задаёт
`LevelLayout.portal_kinds` (главный вход всегда пещера).

| Файл | Размер | Что это |
|---|---|---|
| `well.png` | 26×30 | Сухой колодец с верёвкой вниз |
| `crypt.png` | 34×32 | Дверь склепа в холме с каменным крестом |
| `ruin_stairs.png` | 36×28 | Ступени вниз между обломками стен |
| `sinkhole.png` | 40×14 | Провал в земле с корнями по краю |

## Поверхность — тайлы и фоны (этап 15)
Генератор: `python3 tools/gen_surface_art.py`. Шесть биомов поверхности
(`data/surface/*.tres`): `forest`, `hills`, `swamp`, `ruins`,
`mountains`, `wasteland`.

| Файл | Размер | Что это |
|---|---|---|
| `assets/sprites/tiles/tiles_surface_<биом>.png` | 64×176 | Атлас тайлов, раскладка как у всех биомов: ряд 0 скала, 1 грунт, 2 верх с травой/мхом/песком, 3 низ грунта, 4 уступы и лестница, 7 трава-бахрома |
| `assets/sprites/backgrounds/surface_<биом>_far.png` | 320×180 | Небо с облаками (по вертикали не повторяется) |
| `assets/sprites/backgrounds/surface_<биом>_mid.png` | 320×180 | Дальние силуэты: лес, холмы, ивы, руины, пики, шпили |
| `assets/sprites/backgrounds/surface_<биом>_near.png` | 320×180 | Ближние силуэты |

## Поверхность — предметы на земле — `assets/sprites/surface/`
| Файл | Размер | Что это |
|---|---|---|
| `tree_oak.png`, `tree_pine.png`, `tree_willow.png`, `tree_dead.png` | 48×80 | Деревья (у части ствол — лестница к кроне-уступу) |
| `rock_big.png`, `rock_small.png`, `rock_red.png` | 34×24, 16×10, 26×20 | Валуны |
| `bush.png`, `reeds.png` | 24×14, 16×20 | Кусты, камыш у воды |
| `ruin_wall.png`, `ruin_column.png`, `tower_ruin.png` | 40×34, 14×46, 36×96 | Руины, разрушенная башня (внутри лестница и два яруса) |
| `tent.png`, `campfire.png` | 40×28, 18×12 | Лагерь бандитов или охотников, костёр |
| `cart.png` | 44×26 | Повозка странствующего торговца |
| `gravestone.png`, `well.png` | 12×16, 24×30 | Кладбище, колодец |

Вода в прудах рисуется кодом (`DungeonLevel._spawn_water`, цвет
`SurfaceBiomeData.water_color`). Погода — частицы (`SurfaceSky`), для
тумана используется `fx/light.png`.
